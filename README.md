# imiasum.ro

Simple static coming-soon site for imiasum.ro

Quick scripts

- npm install
- npm run dev    # start a live-reloading dev server on http://localhost:4321
- npm run build  # copy `index.html` to `dist/`
- npm run start  # serve the built `dist/` on http://localhost:4321

Notes

- The main branch uses a lightweight static server (`live-server`) on port 4321 for development.
- The `development` branch uses Astro and also runs on port 4321 by default.
